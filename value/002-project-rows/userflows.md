# Navigator でプロジェクトを行として扱う — ユーザフロー

feature-id: 002-project-rows

## 利用者型

| 型 | 特徴 | 該当フロー |
|---|---|---|
| 片付ける iwase | 作業が一段落したプロジェクトのセッションを消す | UF-002-001, 004 |
| 眺める iwase | 一覧を j/k で辿り、プロジェクト起点で次を決める | UF-002-002, 003 |
| 代理の Claude / CLI | `tower project rm` を非対話で呼ぶ | UF-002-004 |

## フロー

UF-002-001: プロジェクトのセッションを全部消しても、プロジェクトは一覧に残る
  利用者型 : 片付ける iwase
  前提     : プロジェクト foo にセッションが 2 つ。foo は台帳に載っている(自動登録)
  経路     :
    1. foo のセッションにカーソルを合わせ D で消す(×2)
    2. 一覧を見る
  完了     : foo の見出し行が残り、その下にセッション行が無い。カーソルは foo の見出しにある
  得る価値 : 数日後に j/k で foo に辿り着ける。picker で探さなくてよい
  関連要求 : REQ-002-001, REQ-002-002, REQ-002-003, REQ-002-004, REQ-002-005, REQ-002-024
  検証区分 : 機械判定可
  優先度   : 中核

UF-002-002: 見出しにカーソルを止め、右 pane でプロジェクトの状態を見る
  利用者型 : 眺める iwase
  前提     : 一覧に foo(セッション 0)と bar(セッション 2)がある。Navigator 動作中
  経路     :
    1. j/k で foo の見出しに止める
    2. 右 pane を見る
    3. j で bar の見出しに止め、さらに j で bar の最初のセッション行へ
  完了     : foo で止まったとき右 pane にディレクトリ・ブランチ・「0 sessions」・n のヒント。bar のセッション行に移ると右 pane はそのセッション
  得る価値 : 選んでいるものと画面が一致し、空のプロジェクトでも次の一手が分かる
  関連要求 : REQ-002-006, REQ-002-007, REQ-002-008, REQ-002-009, REQ-002-010, REQ-002-025
  検証区分 : 機械判定可
  優先度   : 中核

UF-002-003: 見出しからそのプロジェクトで新セッションを始める
  利用者型 : 眺める iwase
  前提     : foo の見出しにカーソル。foo はディスク上に存在する
  経路     :
    1. n(または Enter、f)を押す
    2. 一覧を見る
  完了     : foo の見出し直下に新しいセッション行が現れ、選ばれている。右 pane は新セッション
  得る価値 : プロジェクトの選択 1 回 + キー 1 回で開始できる
  関連要求 : REQ-002-011, REQ-002-023
  検証区分 : 機械判定可
  優先度   : 中核

UF-002-004: 不要になったプロジェクトを一覧から外す
  利用者型 : 片付ける iwase / 代理の Claude
  前提     : foo はセッション 0。bar はセッション 1
  経路     :
    1. foo の見出しで D → 確認 → 行が消える
    2. bar の見出しで D → 「セッションが 1 件ある」と断られ、何も変わらない
    3. CLI から `tower project rm ~/working/baz`(セッション 0)→ 台帳から消える
    4. CLI から `tower project rm ~/working/bar` → 終了コード 1、件数が示される
  完了     : 外せるのはセッション 0 のプロジェクトだけで、副作用が無い
  得る価値 : 台帳ファイルを手で触らずに一覧を整えられる
  関連要求 : REQ-002-012, REQ-002-014, REQ-002-015, REQ-002-020, REQ-002-021, REQ-002-022
  検証区分 : 機械判定可
  優先度   : 重要

UF-002-005: 見出しで意味の無いキーを押しても何も壊れない
  利用者型 : 眺める iwase
  前提     : foo の見出しにカーソル
  経路     :
    1. i / r / t / w を押す
  完了     : 1 行のヒントが出て、一覧も選択も変わらない
  得る価値 : 見出し行が増えても既存のキーで事故が起きない
  関連要求 : REQ-002-013
  検証区分 : 機械判定可
  優先度   : 周辺
