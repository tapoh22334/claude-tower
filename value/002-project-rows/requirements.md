# Navigator でプロジェクトを行として扱う — 要求

## 機能要求 — 台帳(E-001, E-007, E-011)

REQ-002-001 [Ubiquitous]
システムは常に、プロジェクト台帳(`$TOWER_METADATA_DIR/projects.list`、1 行 1 つの
正規化された絶対パス)を一覧の見出しの源としなければならない。台帳にある
ディレクトリはセッションが 0 でも見出しとして一覧に現れなければならない。

  由来: VH-001 / UF-002-001 / E-001
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-002 [Event-driven]
新しいセッションがディレクトリで開始されたとき(Navigator の n / N / f、
`tower add <dir>` / `open` / `project new`)、システムはそのディレクトリを
台帳に登録しなければならない(既にあれば二重に書かない)。

  由来: VH-001 / UF-002-001 / E-007
  検証: 単体テスト + 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-003 [Event-driven]
セッションが削除されたとき、システムは台帳を変更してはならない。

  由来: VH-001 / UF-002-001 / E-001
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-004 [Ubiquitous]
システムは常に、台帳の書き換えを一時ファイルへの書き出しと `mv` による置換で
行い、`list_metadata` の `*.meta` グロブと衝突しないファイル名を使わなければ
ならない。

  由来: E-007 / harness DEF-T3
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-005 [State-driven]
台帳ファイルが存在しない間、システムは一覧の構築時に、現在セッションを持つ
ディレクトリ全部で台帳を初期化しなければならない(導入直後に見出しが減らない)。

  由来: E-011 / UF-002-001
  検証: 単体テスト (機械判定可)
  優先: 任意

## 機能要求 — 見出し行(E-002, E-003, E-010)

REQ-002-006 [Ubiquitous]
システムは常に、各プロジェクトの見出しを一覧の 1 行(id `dir:<絶対パス>`)として
扱い、j/k/先頭/末尾の移動でカーソルが止まるようにしなければならない。

  由来: VH-002 / UF-002-002 / E-002
  検証: 単体テスト + 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-007 [State-driven]
見出し行が選ばれている間、システムは `selected` 状態ファイルに `dir:<絶対パス>`
を書き、その行を反転表示しなければならない。

  由来: VH-002 / UF-002-002 / E-002 / E-010
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-008 [State-driven]
`selected` が `dir:` で始まる間、システムは view pane に nested client を付けず、
ディレクトリ・git ブランチ(git repo なら)・セッション数・「n: new session
here」のヒントを描かなければならない。

  由来: VH-003 / UF-002-002 / E-003
  検証: 受入シナリオ (機械判定可: view pane の画面に 4 項目)
  優先: 必須

REQ-002-009 [Ubiquitous]
システムは常に、`selected` が `dir:` で始まるとき、Tile / Tail / Queue / 
`nav_redirect_view` / `tower` CLI が失敗や異常終了をせず、セッションの選択が
無いときと同じ振る舞いをしなければならない。

  由来: E-002 / harness DEF-T5
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-010 [Ubiquitous]
システムは常に、一覧のキャッシュに見出し行を他の行と同じ形式(`ROW id display
dir header`)で直列化しなければならない。

  由来: E-002 / harness DEF-T5
  検証: 単体テスト (機械判定可)
  優先: 必須

## 機能要求 — 見出しでの操作(E-004, E-005, E-006, E-009)

REQ-002-011 [Event-driven]
利用者が見出し行で `n`、`Enter`、`f` のいずれかを押したとき、システムはその
ディレクトリで新しいセッションを開始し、その行を見出しの直下に座らせ、
選択をその行に移さなければならない。

  由来: VH-002 / UF-002-003 / E-004 / E-005
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-012 [Event-driven]
利用者がセッションを 1 つも持たない見出し行で `D` を押したとき、システムは
確認の後にそのディレクトリを台帳から外し、行を一覧から消さなければならない。

  由来: UF-002-004 / E-006
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-013 [Event-driven]
利用者が見出し行で `i`、`r`、`t`、`w` のいずれかを押したとき、システムは
何も変更せず、「見出しでは n / Enter で新規、D で台帳から外す」の 1 行を
表示しなければならない。

  由来: E-009
  検証: 単体テスト (機械判定可)
  優先: 任意

## 機能要求 — CLI(E-008)

REQ-002-014 [Event-driven]
利用者が `tower project rm <dir>` を実行したとき、システムはそのディレクトリに
セッションが無ければ台帳から外し、正規化したパスを標準出力に 1 行で出力
しなければならない。

  由来: UF-002-004 / E-008
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-015 [Ubiquitous]
システムは常に、`tower help` に `project rm` の書式と 1 行説明を含めなければ
ならない。

  由来: E-008
  検証: 単体テスト (機械判定可)
  優先: 任意

## 異常系要求

REQ-002-020 [Unwanted]
もし利用者がセッションを 1 つ以上持つ見出し行で `D` を押したならば、システムは
台帳もセッションも変更せず、「セッションが N 件ある。先に消す」の 1 行を
表示しなければならない。

  由来: UF-002-004 / E-006
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-021 [Unwanted]
もし `tower project rm <dir>` の対象にセッションがあるならば、システムは台帳を
変更せず、件数を標準エラー出力に示し、終了コード 1 で終了しなければならない。

  由来: UF-002-004 / E-008
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-022 [Unwanted]
もし `tower project rm <dir>` の対象が台帳に無いならば、システムは「登録されて
いない」と示し、終了コード 1 で終了しなければならない。

  由来: E-008
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-023 [Unwanted]
もし見出し行のディレクトリがディスク上に存在しないならば、見出し行での `n` /
`Enter` / `f` でシステムはセッションを作らず、「ディレクトリが無い」の 1 行を
表示し、見出しは残さなければならない(D で外せる)。

  由来: UF-002-003 / E-004
  検証: 単体テスト + 受入シナリオ (機械判定可)
  優先: 必須

REQ-002-024 [Unwanted]
もし台帳ファイルが読めない、または壊れた行(空行・相対パス)を含むならば、
システムはその行を無視して一覧を構築し、異常終了してはならない。

  由来: E-001 / harness DEF-T2
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-002-025 [Unwanted]
もし一覧が見出し行だけ(セッション 0)、または行が 0 であるならば、システムは
j/k/Enter/D で異常終了せず、Enter は見出しのディレクトリで新セッションを
開始しなければならない。

  由来: UF-002-002 / E-002(空状態)
  検証: 単体テスト (機械判定可)
  優先: 必須

## 矛盾点検の記録

| 組 | 衝突の内容 | 判断 | 根拠 |
|---|---|---|---|
| REQ-002-003 × REQ-002-012 | 削除で台帳を変えない vs D で外す | 両立 | 003 はセッション削除、012 は見出し行への明示操作 |
| REQ-002-006 × 既存の楽観挿入(#46) | 新行を「グループの先頭」に座らせる既存論理 | 更新 | 見出しが行になるので「見出しの直下、id 順」に改める(REQ-002-011) |
| REQ-002-008 × REQ-002-009 | view はカードを描く vs 他 view は無選択扱い | 両立 | view pane だけが `dir:` を解釈する。Tile/Tail/Queue はセッション一覧なので無選択で正しい |
| 非スコープ(件数表示 E-012)× REQ-002-008 | カードにセッション数 | 衝突なし | 見出し行には出さない。カード(右 pane)には出す |
