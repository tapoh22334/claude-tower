# Navigator でプロジェクトを行として扱う — 分節

feature-id: 002-project-rows
由来: value/002-project-rows/orient.md

> 適用範囲は**利用者との境界面**。内部設計は対象外(構築層の仕事)。

## 境界面の要素

| ID | 要素 | 説明 |
|---|---|---|
| E-001 | 空のプロジェクトが一覧に残る | セッション 0 でも見出しが出る |
| E-002 | 見出しにカーソルが止まる | j/k で見出し行を選べる。全部の見出し |
| E-003 | 見出し選択時のカード | 右 pane にディレクトリ・git ブランチ・セッション数・`n` のヒント |
| E-004 | 見出しで `n` / `Enter` | そのプロジェクトで新セッション。新行が見出し直下に出て選ばれる |
| E-005 | 見出しで `f` | `n` と同じ(fork here の自然な拡張) |
| E-006 | 見出しで `D` | セッション 0 なら台帳から外す(確認あり)。あれば断る |
| E-007 | 自動登録 | セッションを始めたディレクトリは何もしなくても台帳に載る |
| E-008 | `tower project rm <dir>` | CLI から台帳を外す。セッションがあれば exit 1 |
| E-009 | 見出しでの `i` / `r` / `t` / `w` | 無視して 1 行のヒント |
| E-010 | 見出しの見た目 | 行として選ばれたとき反転表示。セッション数の表示 |
| E-011 | 初回移行 | 既存利用者の現在のプロジェクトが最初から台帳に載る |
| E-012 | 見出しのセッション数表示 | `foo (3)` のような件数 |
| E-013 | 空プロジェクトの印 | セッション 0 の見出しに「empty」等の目印 |

## 第1段: 実装を括弧に入れる

| ID | 完全技術でも残るか | 残らないなら何の回避策か |
|---|---|---|
| E-001 | 残る | 「戻る場所を覚えている」は意図そのもの |
| E-002 | 残る | プロジェクトを操作対象にするには選べなければならない |
| E-003 | 残る | 選んだものを見せるのは完全技術でも必要 |
| E-004 | 残る | 意図の表現 |
| E-005 | 残らない | `n` と結果が同じ。既存キーとの整合のための別名 |
| E-006 | 残る | 「覚えなくてよい」も意図 |
| E-007 | 残らない | 完全技術なら台帳自体が不要(すべてを知っている) |
| E-008 | 残らない | 完全技術なら呼び出し側が直接知っている。プロセス境界の回避策。ただし #67 の「CLI が正、スキルが呼ぶ」方針から要る |
| E-009 | 残らない | 操作が意味を持たない場面での礼儀 |
| E-010 | 残らない | 選択の可視化は実装の都合 |
| E-011 | 残らない | 台帳導入という実装の都合への回避策 |
| E-012 | 残らない | 行を数えれば分かる |
| E-013 | 残らない | 行が無いことで分かる |

## 第2段: 文脈と不適合から本体を定義

### misfit 列挙(際立つ順)

1. **プロジェクトがセッションの影でしかない** — 利用者の単位はプロジェクトなのに、一覧の単位はセッション。応える要素: E-001, E-002
2. **見出しから何もできない** — 見出しは読むだけで操作の起点にならない。応える要素: E-004, E-006
3. **選んだものと画面が食い違う** — 見出しに止まれるようになると、右 pane が直前のセッションのままでは嘘になる。応える要素: E-003
4. **台帳を手で育てたくない** — 登録を意識させると使われない。応える要素: E-007, E-011
5. **CLI/スキルからも同じことができるべき** — #67 の方針。応える要素: E-008

### breakdown の想像

| ID | これが壊れたとき、利用者は何に気づくか |
|---|---|
| E-001 | セッションを消した翌日、プロジェクトが一覧に無く picker で探す(今日の姿) |
| E-002 | j を押すと見出しを飛び越える。見出しで何かしたいのに止まれない |
| E-003 | 見出しに止まったのに右 pane は別のセッション。Enter で何が起きるか分からない |
| E-004 | 見出しで n を押しても呼び出し元の cwd で始まる。「ここで」が効かない |
| E-006 | 不要になったプロジェクトが一覧に居座り続け、台帳ファイルを手で編集する |
| E-007 | `project new` で作ったプロジェクトが、セッションを閉じた瞬間に消える |
| E-011 | 導入直後、今まで見えていたプロジェクトが(セッション 0 のものは)消える |

### purpose / operational principle

| ID | purpose | operational principle |
|---|---|---|
| E-001 | 戻る場所を覚える | 台帳のディレクトリは行が 0 でも見出しを出す |
| E-002 | プロジェクトを操作対象にする | 見出しを行として配列に載せ、j/k は行を数える |
| E-003 | 選んだものを見せる | 選択が `dir:` なら view は nested client を外してカードを描く |
| E-004 | ここで始める | `open_session_in_dir <dir>` を呼び、新行を見出し直下に座らせる |
| E-006 | 覚えなくてよい | セッション 0 の見出しで D → 台帳から行を外す |
| E-007 | 台帳を意識させない | `start_claude_session`(new)で登録 |

## 第3段: 変化させて不変を取り出す

| ID | 無くす | 弱める | 強める | 判定 |
|---|---|---|---|---|
| E-001 | 機能の半分が消える | 「最近 N 日」だけ残す → 消える時期が読めず不安 | 全 transcript の cwd を残す → 一覧が肥大 | 不変核 |
| E-002 | 空プロジェクトに何もできない | 空の見出しだけ止まる → 挙動が場所で変わり迷う | — | 不変核 |
| E-003 | 見出しで止まると右 pane が嘘をつく | ディレクトリ名だけ → 成立する | ファイル一覧まで → 要らない | 不変核(内容は薄くてよい) |
| E-004 | 見出しに止まれる意味が半減 | Enter だけ → n と揃わず迷う | — | 不変核 |
| E-005 | n を押せばよい | — | — | 無関心(揃える) |
| E-006 | 台帳が増える一方 | CLI だけ → 一覧を見ながら外せない | — | 不変核(弱く) |
| E-007 | 手動登録になり使われない | — | — | 不変核 |
| E-008 | 見出しで D すればよい。スキルからは外せない | — | — | 無関心(#67 の方針で残す) |
| E-009 | 見出しで i を押すと何が起きるか不明(セッション id 無しで動く) | — | — | 無関心(安全のため最小実装) |
| E-010 | 選ばれているのに見た目が変わらない | — | — | 無関心(既存の反転表示に乗る) |
| E-011 | 導入直後に空プロジェクトが「消えた」ように見える(現状と同じ) | — | — | 除去可(台帳が空なら初回は今の見出しを取り込む、で 1 行の実装) |
| E-012 | 見出しだけで件数が分からない。行を見れば分かる | — | — | 除去可 |
| E-013 | 行が無いことで分かる | — | — | 除去可 |

## 第4段: 関節で切る

### 変わりやすい設計判断

1. 台帳の置き場と形式(1 ファイル 1 行 → 将来は metadata 風の key=value かもしれない)
2. 選択状態の表現(`dir:<path>` → 将来は種類と値を分けるかもしれない)
3. カードの内容(git ブランチ等は増減する)
4. 見出し行の操作セット(n/f/Enter/D → 増えるかもしれない)

### 切断の妥当性

| 切断面 | 自然な関節か | 根拠 |
|---|---|---|
| 台帳(E-001/007/008)と行モデル(E-002) | 関節 | 台帳の形式が変わっても行モデルは不変 |
| 行モデル(E-002)と view のカード(E-003) | 関節 | 選択の表現だけが境界。カードの中身は独立に変えられる |
| 行モデルと見出しでの操作(E-004/005/006/009) | 関節 | 操作は「選択が dir: のとき」の分岐として足す |
| Navigator 内の操作(E-006)と CLI(E-008) | 関節 | 両方が同じ台帳関数を呼ぶ |

三分: core = E-001, E-002, E-003, E-004, E-007 / supporting = E-006, E-008 /
generic = E-005, E-009, E-010 / omittable = E-011, E-012, E-013

## 第5段: 中心から展開する

| ID | 全体を強めるか | 根拠 | 反証条件 |
|---|---|---|---|
| E-001 | 強める | misfit 1 への直接の答え | 台帳が肥大して「まとめて消したい」要望が出る |
| E-002 | 強める | 見出しが操作対象になる前提 | 利用者が見出しを飛ばすキーを求める |
| E-003 | 強める | 見出しに止まれるなら右 pane が追従しないと不一致 | 「前のセッションを映し続けてほしい」と言われる |
| E-004 | 強める | 見出し選択の主用途 | 見出しでの n が使われず f/N のまま |
| E-005 | 中立 | 揃えるだけ | 見出しで f を押した利用者が「fork here が効かない」と報告する(= generic でも必要だった) |
| E-006 | 強める(弱く) | 台帳を手で触らずに済む | 使われず、`tower project rm` だけで足りている |
| E-007 | 強める | 登録を意識させないことが台帳が使われる条件 | 利用者が登録されていないプロジェクトに気づく |
| E-008 | 中立 | #67 の方針との整合 | スキルから一度も呼ばれない |
| E-009 | 中立 | 事故防止 | 見出しで i/r/t/w に意味を持たせたくなる → 格上げ |
| E-010 | 中立 | 既存の反転表示 | 見出しが選ばれていると分からない |
| E-011 | 中立 | 1 行の実装で導入時の違和感を消す | 導入直後に「プロジェクトが消えた」という報告が出る |
| E-012 | 中立 | 行を見れば分かる | 利用者が件数表示を求める |
| E-013 | 中立 | 行が無いことで分かる | 空の見出しを見て「セッションがあるのに表示されていない」と誤認する報告が出る |

ばらついた要素への対処:

- E-003: 2 回目は「ディレクトリ名だけなら薄い」と見たが、breakdown(右 pane が嘘をつく)が
  具体的に書けるので **core**。内容は薄くてよい。
- E-005: `f` は既存キーなので無視すると「fork here が効かない」と見える。**generic**
  (n と同じ経路に落とすだけ)。
- E-011: 1 行の実装(台帳が無ければ現在の見出しを取り込む)で導入直後の「消えた」を防げる。
  費用が小さいので **generic** に格上げして実装する。E-012/E-013 は omittable のまま。

### misfit 検証

| ID | 欠けたときに起きる具体的な破綻 |
|---|---|
| E-001 | セッションを全部消した翌日、利用者はプロジェクトを `N` の picker から名前で探す |
| E-002 | j/k が見出しを飛び越え、空プロジェクトには何もできない |
| E-003 | 見出しに止まっているのに右 pane は別セッション。Enter で何が起きるか読めない |
| E-004 | 見出しで n を押しても呼び出し元 cwd で始まり、「ここで」が効かない |
| E-007 | `project new` で作ったプロジェクトが、セッションを閉じた瞬間に一覧から消える |

## 分節(結論)

| ID | 要素 | タグ | 下流での扱い |
|---|---|---|---|
| E-001 | 空プロジェクトが残る | core | E2E 必須 |
| E-002 | 見出しにカーソル | core | E2E 必須・異常系(空の一覧、見出しだけの一覧) |
| E-003 | カード | core | E2E 必須(4 項目) |
| E-004 | 見出しで n / Enter | core | E2E 必須・異常系(ディレクトリが消えている) |
| E-007 | 自動登録 | core | 単体 + E2E |
| E-006 | 見出しで D | supporting | E2E(0 件 / 1 件以上) |
| E-008 | `tower project rm` | supporting | 単体 |
| E-005 | 見出しで f | generic | 単体(n と同じ経路) |
| E-009 | 見出しで i/r/t/w | generic | 単体(落ちない) |
| E-010 | 見出しの反転 | generic | 既存に乗る |
| E-011 | 初回移行 | generic | 単体 1 本 |
| E-012 | 件数表示 | omittable | **非スコープへ** |
| E-013 | 空の印 | omittable | **非スコープへ** |

### omittable の送り先

- E-012 件数表示: 行を見れば分かる(第3段)
- E-013 空の印: 行が無いことで分かる(第3段)

### 造り込みの方針

| タグ | 件数 | 方針 |
|---|---|---|
| core | 5 | 異常系まで。実 tmux の E2E。tower-reviewer 必須(共有状態と画面の不一致クラス) |
| supporting | 2 | 正常系 + 主要異常系 |
| generic | 4 | 既存の型どおり、最小 |
| omittable | 2 | 作らない |
