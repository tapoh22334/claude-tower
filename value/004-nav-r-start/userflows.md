# r による休眠セッションの起動 — ユーザフロー

feature-id: 004-nav-r-start

## 利用者型

| 型 | 特徴 | 該当フロー |
|---|---|---|
| 反復利用者 | 1 つのプロジェクトで複数のセッションを使い分け、翌日に再開する | UF-004-001, UF-004-002, UF-004-003 |

## フロー

UF-004-001: 休眠中のセッションを選んで起動し、一覧に留まる
  利用者型 : 反復利用者
  前提     : 一覧に休眠中(○)のセッションの行がある
  経路     :
    1. 休眠中の行へカーソルを移す
    2. r を押す
    3. 行が ◐ になり、カーソルは一覧に残る
    4. 次の休眠中の行へ移り、r を押す
  完了     : 選んだセッションが起動し、焦点は一覧にある
  得る価値 : 起動したいセッションだけを、一覧から移らずに続けて起動できる
  関連要求 : REQ-004-001, REQ-004-004, REQ-004-005, REQ-004-012, REQ-004-013
  検証区分 : 機械判定可
  優先度   : 中核

UF-004-002: 1 つのプロジェクトのセッションをまとめて再開する
  利用者型 : 反復利用者
  前提     : プロジェクトに休眠中のセッションが 2 本以上ある
  経路     :
    1. プロジェクトの見出しの行へカーソルを移す
    2. r を押す
    3. 休眠中の行がすべて ◐ になり、起動した本数が一覧の下に出る
  完了     : そのプロジェクトの休眠中のセッションがすべて起動している
  得る価値 : 翌日の再開が 1 回のキー操作で済む
  関連要求 : REQ-004-002, REQ-004-003, REQ-004-004, REQ-004-011, REQ-004-012
  検証区分 : 機械判定可
  優先度   : 中核

UF-004-003: 起動できない行で r を押し、理由を知る
  利用者型 : 反復利用者
  前提     : カーソルの行が起動中・◇・✗/? のいずれか
  経路     :
    1. r を押す
    2. 理由が一覧の下に出る
  完了     : 何も起動せず、利用者は理由を知っている
  得る価値 : 「r が壊れた」と誤解しない
  関連要求 : REQ-004-010, REQ-004-011
  検証区分 : 機械判定可
  優先度   : 重要
