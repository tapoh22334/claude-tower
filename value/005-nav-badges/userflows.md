# シェルとエージェントのバッジ — ユーザフロー

feature-id: 005-nav-badges

## 利用者型

| 型 | 特徴 | 該当フロー |
|---|---|---|
| 並行利用者 | 複数のセッションで、バックグラウンドでシェルやエージェントを動かす | UF-005-001, UF-005-002 |

## フロー

UF-005-001: バックグラウンドでプログラムが動いているセッションを一覧で見つける
  利用者型 : 並行利用者
  前提     : あるセッションで dev サーバーをバックグラウンドで動かし、Claude はプロンプト待ちである
  経路     :
    1. Navigator の一覧を見る
    2. その行にスピナーと ⚙1 が付いている
    3. 終了したセッションの残った画面には ⚙ が付いていない
  完了     : プログラムが動いているセッションを、開かずに特定できる
  得る価値 : 止め忘れたプログラムを見つけられる
  関連要求 : REQ-005-001, REQ-005-002, REQ-005-005, REQ-005-010
  検証区分 : 機械判定可
  優先度   : 中核

UF-005-002: 動いているのがエージェントかシェルかを見分ける
  利用者型 : 並行利用者
  前提     : エージェントだけ、シェルだけ、両方が動いているセッションがある
  経路     :
    1. 一覧を見る
    2. 行ごとに ✦N・⚙N・✦N ⚙N のいずれかが、アイコンのすぐ右に表示されている
    3. タイトルはどの行も同じ桁から始まる
    4. 意味がわからなければ ? でヘルプを開く
  完了     : 待てば終わる作業か、判断が要るプログラムかを見分けられる
  得る価値 : 開くべきセッションを選べる
  関連要求 : REQ-005-003, REQ-005-004, REQ-005-006, REQ-005-007, REQ-005-011
  検証区分 : 機械判定可
  優先度   : 中核
