# シェルとエージェントのバッジ — 要求

feature-id: 005-nav-badges
由来: value/005-nav-badges/orient.md

## 機能要求

REQ-005-001 [State-driven]
Claude の pane の下部に `· N shell` または `· N shells`(N は 1 以上)が表示されている間、システムはそのセッションを作業中としてスピナーで表示しなければならない。
  由来: VH-001 / UF-005-001
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-002 [State-driven]
作業中のセッションでバックグラウンドのシェルが動いている間、システムは状態アイコンのすぐ右に `⚙N`(N はシェルの数)を表示しなければならない。
  由来: VH-001 / UF-005-001
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-003 [State-driven]
作業中のセッションでエージェントが動いている間、システムは状態アイコンのすぐ右に `✦N`(N はエージェントの数)を表示しなければならない。両方あるときは `✦N` を先、`⚙N` を後に並べなければならない。
  由来: VH-002 / UF-005-002
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-004 [Ubiquitous]
システムは常に、一覧のすべてのセッション行のタイトルを同じ桁から始めなければならない。バッジ欄の幅は、その一覧で最も長いバッジに合わせなければならない。
  由来: VH-002 / UF-005-002
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-005 [Ubiquitous]
システムは常に、一覧のどの行にもバッジがないとき、バッジ欄を設けずに行を描画しなければならない。
  由来: VH-001 / UF-005-001
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-006 [Ubiquitous]
システムは常に、行の右端に記号用の幅を予約せず、その幅をタイトルに使わなければならない。
  由来: VH-002 / UF-005-002
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-007 [Ubiquitous]
システムは常に、ヘルプに `✦` と `⚙` の意味を表示し、ヘルプ全体を 80×24 の画面に収めなければならない。
  由来: VH-002 / UF-005-002
  検証: 受入シナリオ (機械判定可)
  優先: 必須

## 異常系要求

REQ-005-010 [Unwanted]
もし `· N shell` の行の後ろに、エージェント一覧の行以外の行があるならば(Claude が終了し、シェルのプロンプトが出ている場合)、システムはシェルを数えてはならない。
  由来: VH-001
  検証: 受入シナリオ (機械判定可)
  優先: 必須

REQ-005-011 [Unwanted]
もし起動中・削除中の行を再構築を待たずに描画するならば、システムはその行のタイトルを、ほかの行と同じ桁から始めなければならない。
  由来: VH-002
  検証: 受入シナリオ (機械判定可)
  優先: 必須

## 矛盾点検の記録
