## 6. 欠陥クラスの更新

- **新規 DEF-T12**(一時的なモードの後の端末状態)の追記: 端末状態には echo とカーソルだけでなく、**描画の幅の予算**も含む。行の前に列を足すモードは、行の幅を同じだけ削る。今回はレビューで捕まえた。単体テストは短い表示文字列しか使っていなかった。そのため、全幅の行で描くテストを足した。
- **新規 DEF-T13**(外部コマンドの引数の取り違え): `--session-id` と `--resume` の組には `--fork-session` が要る。単体で起動コマンドの文字列を検査する。
- ID の衝突: 002 の retro が DEF-T11 を別のクラス(タイマーの条件)に使っていた。003 の harness で T11 と T12 を採番していたため、T12 と T13 に振り直した。欠陥クラスの一覧がリポジトリに無いことが原因である。

## 追記: #106 の改訂

- **価値仮説の外れ(VH-001、`i` について)**: 外れ判定「削ったキーを別名として戻すよう求める」が、マージの直後に `i` で起きた。vim の「入力に入る」という指の癖を、第 3 段の反例(無くす)で「Enter と重複するだけ」と軽く見た。重複は害だが、意味が同じ重複は行の種類での食い違いを生まない。分節の第 3 段では、重複を「意味が違う重複」と「同じ意味の別名」に分けて判定する。
- **ラベルの打ち方の不統一(REQ-003-023)**: 見出しの行だけ「1 文字 + Enter」にしていた。要求の工程で「どの行も同じ打鍵数」という観点を持っていれば防げた。差し戻し先は vf-requirements である。
