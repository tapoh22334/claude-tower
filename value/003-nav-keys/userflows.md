# Navigator のキーを整理し、copy とラベルジャンプを足す — ユーザフロー

feature-id: 003-nav-keys

> 1フロー = 利用者がひとつの目的を達成する、開始から完了までの一連の操作である。
> 「得る価値」が書けないフローは目的がない。

## 利用者型

| 型 | 特徴 | 該当フロー |
|---|---|---|
| 初回利用者 | 整理前のキー(`i` / `r` / `A` / 旧 `f`)が指に残っている iwase | UF-003-007 |
| 反復利用者 | 40 行前後の一覧を毎日操作する iwase | UF-003-001〜006, UF-003-008 |

## フロー

UF-003-001: 一覧から目的のセッションに入り、続きを打つ
  利用者型 : 反復利用者
  前提     : 一覧に動いているセッション、休眠中のセッション、外部のセッションが並んでいる
  経路     :
    1. j/k で目的の行に移る
    2. Enter を押す
    3. 動いている行なら、そのまま表示ペインへ焦点が移る
    4. 休眠中の行なら、行が `◐` になって再開され、表示ペインへ焦点が移る
    5. 外部の行なら、再開を試みずに表示ペインへ焦点が移る
    6. 再開に失敗したら、理由が一覧の下に出て、一覧に留まる
  完了     : 目的のセッションの入力欄に打ち込める状態
  得る価値 : 行の状態を気にせず、Enter 1 つでセッションに入れる
  関連要求 : REQ-003-002, REQ-003-003, REQ-003-004, REQ-003-033, REQ-003-037
  検証区分 : 機械判定可
  優先度   : 重要

UF-003-002: 長い会話を複製し、別の方針を試す
  利用者型 : 反復利用者
  前提     : Tower に登録された、会話の記録があるセッションの行にカーソルがある
  経路     :
    1. `c` を押す
    2. 元の名前に ` copy` を付けた行が `◐` で現れ、選択される
    3. Enter を押して複製に入る
    4. 複製の画面に、元の会話の続きが出る
    5. 別の方針を指示する
  完了     : 元の会話を残したまま、複製で別の方針を進めている
  得る価値 : 今の会話を捨てずに分岐でき、端末で `claude --resume` を打つ手作業が無くなる
  関連要求 : REQ-003-010, REQ-003-011, REQ-003-012, REQ-003-013
  検証区分 : 機械判定可(複製の画面に元の会話が出ることは手で 1 回確かめる)
  優先度   : 中核

UF-003-003: 離れたプロジェクトのセッションへラベルで移る
  利用者型 : 反復利用者
  前提     : 一覧に 10 前後のプロジェクトがあり、カーソルは一覧の上の方にある
  経路     :
    1. `f` を押す
    2. 見出しの行に `a` `b` `c`…、セッション行に `aa` `ab`… のラベルが出る
    3. 3 番目のプロジェクトのラベル `c` を押す
    4. そのプロジェクトのラベルだけが残る
    5. 先頭のセッションのラベル `a` を押す
  完了     : カーソルが 3 番目のプロジェクトの先頭セッションにあり、ラベルが消えている
  得る価値 : どの行へも打鍵 3 回で届き、j/k の連打が要らない
  関連要求 : REQ-003-020, REQ-003-021, REQ-003-022, REQ-003-024
  検証区分 : 機械判定可
  優先度   : 中核

UF-003-004: 今見ているプロジェクトに新しいセッションを足す
  利用者型 : 反復利用者
  前提     : カーソルがあるプロジェクトのセッション行か見出しの行にある
  経路     :
    1. 見出しの行なら Enter を押し、そのプロジェクトで新しいセッションが始まる
    2. セッション行なら `a` を押す。場所の候補の先頭に、そのプロジェクトのディレクトリが出る
    3. そのまま確定する
  完了     : 新しいセッションの行が、そのプロジェクトの下に `◐` で現れる
  得る価値 : 場所を打ち直さずに、今見ているプロジェクトでセッションを始められる
  関連要求 : REQ-003-002, REQ-003-005, REQ-003-006
  検証区分 : 機械判定可
  優先度   : 周辺

UF-003-005: 複製できない行で `c` を押し、理由を知る
  利用者型 : 反復利用者
  前提     : カーソルが外部のセッション、見出しの行、または会話の記録が無いセッションの行にある
  経路     :
    1. `c` を押す
    2. 複製は起動されず、理由が一覧の下に出る
    3. 複製の起動そのものが失敗したときも、理由が出て、複製の行は残らない
    4. 会話の記録がある行へ移り、もう一度 `c` を押す
  完了     : 理由を理解し、複製できる行で複製をやり直している
  得る価値 : `c` が壊れたのか断られたのかを迷わない
  関連要求 : REQ-003-030, REQ-003-031, REQ-003-032
  検証区分 : 機械判定可
  優先度   : 重要

UF-003-006: ジャンプで見出しへ移る、または押し間違えて取り消す
  利用者型 : 反復利用者
  前提     : `f` を押してラベルが出ている
  経路     :
    1. 見出しのラベルを押してから Enter を押すと、その見出しの行へ移る
    2. 押し間違えたら Esc か、どのラベルにも当たらないキーを押す。カーソルは動かずにラベルが消える
    3. ラベルの表示中に移動先の行が一覧から消えたら、カーソルは動かずに一覧へ戻る
  完了     : 見出しの行にいるか、`f` を押す前の位置に戻っている
  得る価値 : 見出しの行にも届き、押し間違えても元の位置を失わない
  関連要求 : REQ-003-023, REQ-003-034, REQ-003-035
  検証区分 : 機械判定可
  優先度   : 重要

UF-003-007: 整理後の一覧を初めて開き、キーを覚え直す
  利用者型 : 初回利用者
  前提     : `make update` で整理後の版に更新し、Navigator を開き直した
  経路     :
    1. 指の癖で `r` や `i` を押す。何も起きない
    2. `?` でヘルプを開く。17 個のキーが並んでいる
    3. フッターに、ヘルプにあるキーだけが並んでいることを確かめる
  完了     : 削ったキーの代わりが Enter と `a` であると分かっている
  得る価値 : ヘルプとフッターだけで新しいキーを覚え直せる
  関連要求 : REQ-003-001, REQ-003-007
  検証区分 : 機械判定可
  優先度   : 周辺

UF-003-008: 見出しが 1 つも無い一覧で `f` を押す
  利用者型 : 反復利用者
  前提     : 一覧にプロジェクトもセッションも無い
  経路     :
    1. `f` を押す
    2. ジャンプのモードに入らず、通常の一覧のままになる
  完了     : 一覧が操作を受け付ける状態のまま
  得る価値 : 空の一覧で操作が固まらない
  関連要求 : REQ-003-036
  検証区分 : 機械判定可
  優先度   : 周辺
