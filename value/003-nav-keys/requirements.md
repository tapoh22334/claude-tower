# Navigator のキーを整理し、copy とラベルジャンプを足す — 要求

feature-id: 003-nav-keys
由来: value/003-nav-keys/orient.md, articulation.md

> 書式は EARS 5型である。`lint-requirements.py` が検査する。
> 分節: core = E-001/004/007、supporting = E-003/005/006/008/009、generic = E-002/010。
> omittable の E-011/012/013 は要求を起こさない。

## 機能要求 — キーの整理(E-001, E-002, E-003, E-010)

REQ-003-001 [Ubiquitous]
システムは常に、一覧で次の 18 個のキーだけを受け付けなければならない:
`j` `k` `g` `G` `/` `n` `N` Enter `i` `a` `c` `f` `D` Tab `t` `w` `?` `q`。
`i` は Enter と同じ処理に渡さなければならない。`A` は何もしてはならない(`r` は 004-nav-r-start で起動のキーとして戻した)。

  由来: VH-001 / UF-003-001 / E-010
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-002 [Ubiquitous]
システムは常に、Enter(と同じ `i`)と D 以外のキーを、セッション行と見出しの行のどちらで
押しても同じ処理に渡さなければならない。

  由来: VH-001 / UF-003-001 / E-001, E-002
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-003 [Event-driven]
動いているセッションの行で Enter を押したとき、システムは表示ペインへ
入力の焦点を移さなければならない。

  由来: VH-001 / UF-003-001 / E-001
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-004 [Event-driven]
休眠中(`○`)のセッションの行で Enter を押したとき、システムはそのセッションを
再開し、行を `◐` にしなければならない。その後、システムは表示ペインへ入力の
焦点を移さなければならない。

  由来: VH-001 / UF-003-001 / E-001
  検証: 単体テスト + 受入シナリオ (機械判定可)
  優先: 必須

REQ-003-005 [Event-driven]
見出しの行で Enter を押したとき、システムはそのプロジェクトのディレクトリで
新しいセッションを始めなければならない。

  由来: VH-001 / UF-003-001 / E-001
  検証: 既存の単体テスト (機械判定可)
  優先: 必須

REQ-003-006 [Event-driven]
`a` を押したとき、システムは新しいセッションの場所の初期値を、カーソルの行が
属するプロジェクトのディレクトリにしなければならない。カーソルの行が
プロジェクトに属さないときは、呼び出し元のディレクトリを初期値にしなければ
ならない。

  由来: VH-001 / UF-003-001 / E-003
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-007 [Ubiquitous]
システムは常に、ヘルプ(`?`)に REQ-003-001 のキーをすべて表示し、フッターには
REQ-003-001 に含まれるキーだけを表示しなければならない(フッターは 80 桁に
収めるため、全部は載せない)。

  由来: VH-001 / UF-003-001 / E-010
  検証: 単体テスト (機械判定可)
  優先: 必須

## 機能要求 — 複製(E-004, E-005)

REQ-003-010 [Event-driven]
Tower に登録されたセッションの行で `c` を押したとき、システムは新しい id で
`claude --resume <元の会話の id> --fork-session --session-id <新しい id>` を
元と同じディレクトリで起動し、新しいセッションを登録しなければならない。

  由来: VH-002 / UF-003-002 / E-004
  検証: 単体テスト + 受入シナリオ (機械判定可)。実際の claude では手で 1 回確かめる
  優先: 必須

REQ-003-011 [Event-driven]
複製を登録したとき、システムは元の名前の後ろに ` copy` を付けた名前を複製に
付けなければならない。元に名前が無いときは `copy` を付けなければならない。

  由来: VH-002 / UF-003-002 / E-005
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-012 [Event-driven]
複製を登録したとき、システムは複製の行を選択し、`◐` で表示しなければならない。

  由来: VH-002 / UF-003-002 / E-004
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-013 [Ubiquitous]
システムは常に、複製の後も元のセッションの状態と会話を変えてはならない。

  由来: VH-002 / UF-003-002 / E-004
  検証: 単体テスト (機械判定可)
  優先: 必須

## 機能要求 — ラベルジャンプ(E-007, E-008, E-009)

REQ-003-020 [Event-driven]
`f` を押したとき、システムはすべての行に 2 文字のラベルを、行の左に表示
しなければならない。1 文字目はプロジェクトの文字(上から `a` `b` `c`…)とする。
2 文字目は、見出しの行なら `a`、セッション行ならプロジェクト内で上から
`b` `c` `d`… とする。

  由来: VH-003 / UF-003-003 / E-007
  検証: 単体テスト + 受入シナリオ (機械判定可)
  優先: 必須

REQ-003-021 [Event-driven]
ラベルの表示中に見出しのラベルの文字を押したとき、システムはそのプロジェクトの
見出しとセッション行のラベルだけを残し、ほかの行のラベルを消さなければならない。

  由来: VH-003 / UF-003-003 / E-008
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-022 [Event-driven]
1 文字目の後にセッションのラベルの文字を押したとき、システムはその行へ
カーソルを移し、ラベルを消さなければならない。その後、システムは通常の一覧に
戻らなければならない。

  由来: VH-003 / UF-003-003 / E-007
  検証: 単体テスト + 受入シナリオ (機械判定可)
  優先: 必須

REQ-003-023 [Event-driven]
1 文字目の後に `a` を押したとき、システムはそのプロジェクトの見出しの行へ
カーソルを移し、通常の一覧に戻らなければならない。

  由来: VH-003 / UF-003-003 / E-009
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-024 [State-driven]
ラベルを表示している間、システムは移動先の行とラベルの対応を、`f` を
押した時点の一覧に固定しなければならない。

  由来: VH-003 / UF-003-003 / E-007
  検証: 単体テスト (機械判定可)
  優先: 必須

## 異常系要求

REQ-003-030 [Unwanted]
もし外部のセッション(`◇`)の行、または見出しの行で `c` を押したならば、
システムは複製を起動せず、複製できない理由を一覧の下に表示しなければならない。

  由来: VH-002 / UF-003-002 / E-006
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-031 [Unwanted]
もし `c` を押した行のセッションに会話の記録(transcript)が無いならば、
システムは複製を起動せず、「会話の記録が無いため複製できない」旨を表示
しなければならない。

  由来: VH-002 / UF-003-002 / E-006
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-032 [Unwanted]
もし複製の起動に失敗したならば、システムは失敗の理由を表示し、
複製のメタデータを残してはならない。

  由来: VH-002 / UF-003-002 / E-004
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-033 [Unwanted]
もし休眠中の行の再開に失敗したならば、システムは失敗の理由を表示し、
表示ペインへ焦点を移さず一覧に留まらなければならない。

  由来: VH-001 / UF-003-001 / E-001
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-034 [Unwanted]
もしラベルの表示中に Esc、Enter、またはどのラベルにも当たらないキーを押したならば、
システムはカーソルを動かさず、ラベルを消して通常の一覧に戻らなければならない。

  由来: VH-003 / UF-003-003 / E-009
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-035 [Unwanted]
もしラベルの表示中に、移動先の行が一覧から消えたならば、システムは
カーソルを動かさず、通常の一覧に戻らなければならない。

  由来: VH-003 / UF-003-003 / E-007
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-036 [Unwanted]
もし一覧に見出しの行が 1 つも無い状態で `f` を押したならば、システムは
ジャンプのモードに入らず、通常の一覧のままでなければならない。

  由来: VH-003 / UF-003-003 / E-007
  検証: 単体テスト (機械判定可)
  優先: 必須

REQ-003-037 [Unwanted]
もし外部のセッション(`◇`)の行で Enter を押したならば、システムは再開を
試みず、表示ペインへ焦点を移すだけにしなければならない。

  由来: VH-001 / UF-003-001 / E-001
  検証: 単体テスト (機械判定可)
  優先: 必須

## 矛盾点検の記録

| 組 | 衝突の内容 | 判断 | 根拠 |
|---|---|---|---|
| REQ-003-020 × REQ-003-023(#106 で改訂) | 見出しの行だけ「1 文字 + Enter」で、ほかの行と打ち方が違った | 見出しの行も 2 文字(`<文字>a`)にし、Enter は取り消しにする | 利用者の指摘。どの行も `f` + 2 文字で届く。1 プロジェクトのセッションは 25 までになる |
| REQ-003-001 × REQ-003-004 | `r` を削ると休眠中の行を再開するキーが無くなる | REQ-003-004 で Enter が再開を引き受ける | VH-001。行への操作を Enter に集める |
| REQ-003-020 × 非スコープ(27 個目以降のラベル) | 27 個目以降の行はラベルで届かない | 27 個目以降の行にはラベルを付けない | E-013 を omittable とした。想定の一覧の規模では 26 に届かない |
| REQ-003-020 × 非スコープ(復旧できないグループ) | `── unrecoverable ──` の下の行はラベルで届かない | ラベルを付けない | E-012 を omittable とした |
| REQ-003-024 × 一覧の自動更新 | ラベルの表示中に一覧が更新されると、ラベルと行がずれる | 表示中は対応を固定し、着地時に行が消えていれば REQ-003-035 で止める | ずれた行へ飛ぶより、動かないほうが害が小さい |
| REQ-003-010 × REQ-003-013 | 同じ会話を 2 つのセッションが書き換える恐れ | `--fork-session` で新しい id に書かせ、元の transcript を変えない | Claude CLI の `--fork-session` の仕様 |
